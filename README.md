# 🔥 Fstreak

> Demo repository for **[AutoStreak](https://github.com/pratham1kruk/AutoStreak)** — a multi-profile desktop app that automates GitHub contribution commits.

---

## What this repo is

Fstreak is not a production project — it's a **live demo target**, created automatically by AutoStreak on first launch, used to validate the app's core commit-and-push loop end to end: token auth, git identity resolution, scheduled commits, and push-to-graph verification.

Every commit here was generated by AutoStreak itself, running against this repo as its test target.

**Demo run:** 11 tracked days, one commit per day, logged in [`streak.txt`](./streak.txt).

---

## Try it yourself

AutoStreak sets all of this up for you — no manual repo creation or pushing required.

1. **[Download AutoStreak](https://github.com/pratham1kruk/AutoStreak_release)**
2. Run the setup wizard — it creates your own streak repo automatically on first launch
3. Add multiple GitHub profiles if you want to run streaks across several accounts
4. Set your schedule, and AutoStreak keeps your contribution graph active in the background — no manual commits or pushes needed

---

## Why it looks the way it does

- `streak.txt` — append-only log; each commit adds one timestamp line, mirroring exactly what AutoStreak writes in production use.
- One commit per day — demonstrates the app's daily quota logic (`contributions_per_day`), not a raw activity dump.
- Commit identity (name/email) is resolved automatically via the GitHub API to match the authenticated account, which is what makes the commits count toward the contribution graph in the first place.
